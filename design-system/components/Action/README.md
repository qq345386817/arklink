Action links provide one prominent App Store destination and a quieter gameplay destination.

Use `<a class="button primary" href="...">` for the store, and `<a class="button secondary" href="...">` for gameplay. Supply meaningful link text and a valid destination. Green fill uses `on-primary` text; secondary outlines use `control-border`. Hover, keyboard focus and reduced-motion states are defined in website CSS. Minimum height is 48px. Do not nest a button inside an anchor.
